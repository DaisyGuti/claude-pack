Notice for ../../agents/reviewer.md

The review instructions in agents/reviewer.md adapt the review prompt and the findings shape
(title, body, confidence, priority, file and line location, an overall verdict) from the
OpenAI Cookbook example examples/codex/build_code_review_with_codex_sdk.md
(https://github.com/openai/openai-cookbook). The text was rewritten for Claude Code, the
output was changed from JSON to a Markdown report, and the severity definitions, the scope
check and the security checklist were added for this pack.
